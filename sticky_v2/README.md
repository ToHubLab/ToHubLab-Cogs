# Sticky_v2 Cog for Red-DiscordBot

A powerful cog that keeps a message pinned at the bottom of a Discord channel. When new messages arrive, the sticky message automatically moves down — no need to delete and repost manually.

## ✨ Features

- 📌 Keep any message at the bottom of a channel
- 🔄 Auto-reposts when new messages arrive
- ⏱️ **Configurable debounce delay** per channel to prevent spam
- 🖱️ **Interactive menu** to manage all stickies in one place
- 📋 Clean overview of all active stickies with previews and delays
- ✏️ Edit stickies without manual deletion
- 🐙 **Credits page** with links to GitHub, website and Discord
- 🔒 Admin-only configuration
- 🎨 Teal-themed embeds matching Finn Bot's branding
