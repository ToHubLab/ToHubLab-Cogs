# Sticky_v1 Cog for Red-DiscordBot

A simple cog that keeps a message pinned at the bottom of a Discord channel. When new messages arrive, the sticky message automatically moves down — no need to delete and repost manually.

## Features

- 📌 Keep any message at the bottom of a channel
- 🔄 Auto-reposts when new messages arrive
- 🗑️ Clean removal with a single command
- 📋 List all sticky messages in a server
- 🔒 Admin-only configuration
